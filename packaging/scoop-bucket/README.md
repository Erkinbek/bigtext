# Scoop bucket for BigText

[BigText](https://github.com/Erkinbek/bigtext) opens, searches and edits text and log files of
any size (1–50+ GB) without freezing.

## Install

```
scoop bucket add bigtext https://github.com/Erkinbek/scoop-bigtext
scoop install bigtext/bigtext
```

`bigtext` opens the window (with a file: `bigtext app.log:120`), `bigtext-cli` is for scripts,
and the Start menu gets a BigText shortcut.

## Update

```
scoop update bigtext
```

The Excavator workflow brings the manifest to each new BigText release within four hours.
