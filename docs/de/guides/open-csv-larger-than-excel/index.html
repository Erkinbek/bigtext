Eine CSV-Datei mit mehr als 1.048.576 Excel-Zeilen öffnen

Das Raster von Excel endet bei Zeile 1.048.576. Bei einer größeren CSV-Datei warnt Excel, dass die Daten zu groß sind, und die Zeilen jenseits der Grenze gehen beim Speichern verloren. Exporte von Logs, Bestellungen oder Datenbanktabellen sind oft größer.

BigText öffnet eine CSV-Datei jeder Größe sofort als Tabelle und lädt sie nie in den Speicher: Eine Datei mit 50 Millionen Zeilen scrollt so schnell wie eine mit fünfzig. Es ist kostenlos und läuft unter Windows, Linux und macOS.

Schritt für Schritt

  1. Datei öffnen

    Laden Sie BigText herunter und öffnen Sie die .csv- oder .tsv-Datei mit Datei → Öffnen oder ziehen Sie sie auf das Fenster. Sie öffnet sich als Tabelle: Das Trennzeichen (Komma, Semikolon, Tabulator oder senkrechter Strich) wird aus den ersten Zeilen erkannt, die erste Zeile wird zur fixierten Kopfzeile. Strg+T wechselt zwischen Tabelle und Text.

  2. Sich zurechtfinden

    Scrollen Sie, drücken Sie Strg+G für eine Zeile oder Strg+F für die Suche in der ganzen Datei; „Alle suchen“ listet jeden Treffer mit seiner Zeile. Auf das Laden muss nichts warten, denn die Datei wird nie geladen.

  3. Ohne Excel auswerten

    Rechtsklick auf eine Spaltenüberschrift: „Statistik…“ (Zeilen, leere und verschiedene Werte, Summe, Mittelwert, Minimum, Maximum und die häufigsten Werte), Filter nach dieser Spalte, „Zeilen nach dieser Spalte gruppieren…“ mit Summen einer anderen Spalte und „Pivot nach dieser Spalte…“. Sortieren funktioniert bei Dateien bis 1 GB.

  4. Oder passend für Excel machen

    Datei → Datei aufteilen… schneidet die CSV-Datei in name.part001.csv, name.part002.csv… mit einer festen Zeilenzahl, etwa 1.000.000, immer an Zeilengrenzen. Die Kopfzeile steht nur im ersten Teil; kopieren Sie sie in die anderen, wenn Ihr Programm sie braucht. Für nur einige Zeilen filtern Sie sie („Zeilen nach Bedingungen filtern…“) und speichern das Ergebnis als neue, kleinere CSV-Datei.

Gut zu wissen

  • Ansicht → Tabellenzeilen prüfen… listet Datensätze mit falscher Feldanzahl, einem verirrten Anführungszeichen oder Text in einer Zahlenspalte, mit ihren Zeilennummern.
  • Dieselben Werkzeuge gibt es für Skripte in bigtext-cli, zum Beispiel bigtext-cli pivot.
