Eine Tabelle aus einer mysqldump-Datei herauslösen

Ein vollständiger mysqldump einer Datenbank kann Dutzende Gigabyte groß sein, und oft brauchen Sie nur eine Tabelle daraus: um sie wiederherzustellen, ihre Daten zu prüfen oder sie weiterzugeben. BigText öffnet den Dump sofort, ohne ihn in den Speicher zu laden, listet seine Tabellen in einem Durchgang auf und schreibt die gesuchte in eine eigene Datei, mit allem, was sie zur Wiederherstellung braucht.

Schritt für Schritt

  1. Den Dump öffnen

    Öffnen Sie die .sql-Datei mit Datei → Öffnen oder ziehen Sie sie auf das Fenster. Ein .sql.gz-Dump öffnet sich ebenfalls direkt.

  2. Die Tabellen auflisten

    „Datei → Tabellen des SQL-Dumps…“ liest den Dump einmal, etwa ein Gigabyte pro Sekunde, und listet seine Tabellen mit ihren Zeilen und Größen auf, in der Reihenfolge des Dumps oder die größten zuerst. Um eine Tabelle unter Hunderten zu finden, tippen Sie einen Teil des Namens in den Filter.

  3. Die Tabelle prüfen

    Ein Klick auf eine Tabelle springt zu ihrer CREATE-TABLE-Anweisung und zeigt ihre Spalten.

  4. In eine Datei speichern

    Klicken Sie mit der rechten Maustaste auf die Tabelle und wählen Sie „Diese Tabelle speichern unter…“. Die Datei erhält die DROP- und CREATE-Anweisungen der Tabelle, ihre Zeilen, Schlüssel, Indizes und Trigger sowie die Einstellungen vom Anfang und Ende des Dumps, darum lässt sie sich für sich wiederherstellen: mysql shop < orders.sql.

Gut zu wissen

  • Mehrere Tabellen: Markieren Sie sie in der Liste und drücken Sie „Die markierten Tabellen als eine Datei speichern…“. „Diese Tabelle in einem neuen Tab öffnen“ zeigt eine Tabelle, ohne sie zu speichern.
  • „In eine Datei je Tabelle aufteilen…“ schreibt eine Datei je Tabelle, eine für das, was vor den Tabellen steht, und eine für Views, Routinen und Fremdschlüssel danach. In der Reihenfolge ihrer Namen stellen sie den ganzen Dump wieder her: for f in shop.*.sql; do mysql shop < "$f"; done.
  • pg_dump-Dateien im Textformat und .dump-Dateien von SQLite funktionieren genauso. In Skripten: bigtext-cli sqldump shop.sql extract orders -o orders.sql.
