mysqldump faylidan bitta jadvalni ajratib olish

Ma'lumotlar bazasining to'liq mysqldump'i o'nlab gigabayt bo'lishi mumkin, undan esa ko'pincha bitta jadval kerak: tiklash, ma'lumotini tekshirish yoki hamkasbga yuborish uchun. BigText dampni xotiraga yuklamasdan darhol ochadi, «Satrlarni eksport qilish…» esa istalgan qatorlar oralig'ini yangi faylga yozadi.

Qadamma-qadam

  1. Dampni oching

    .sql faylni «Fayl → Ochish» orqali yoki oynaga tortib oching. .sql.gz damp ham to'g'ridan-to'g'ri ochiladi.

  2. Jadvallar ro'yxatini oling

    mysqldump har bir jadvalni -- Table structure for table `orders` kabi izoh bilan belgilaydi. -- Table structure for table ni qidiring va «Hammasini topish» ni bosing: natijalarda dampdagi barcha jadvallar qator raqamlari bilan chiqadi.

  3. Jadval boshi va oxirini toping

    Natijalarda kerakli jadvalni bosing, uning qator raqami holat satrida ko'rinadi. Jadval keyingi jadval izohi boshlangan joyda tugaydi: F3 unga o'tadi.

  4. Uni faylga yozing

    «Fayl → Satrlarni eksport qilish…» qatorlar oralig'ini yangi faylga yozadi: jadvalning birinchi qatoridan keyingi jadvaldan oldingi qatorgacha. Natijada CREATE TABLE va shu jadvalning INSERT qatorlari bor kichik .sql fayl hosil bo'ladi.

Bilib qo'ying

  • Damp SET qatorlari (kodirovka, tashqi kalitlar tekshiruvi) bilan boshlanadi. Jadvalga kerak bo'lsa, ularni yangi fayl boshiga ko'chiring.
  • --skip-comments bilan olingan dampda bunday izohlar yo'q: o'rniga CREATE TABLE `orders` va keyingi DROP TABLE IF EXISTS ni qidiring.
  • Faqat ma'lumot: filtr rejimida INSERT INTO `orders` faqat shu jadvalning INSERT qatorlarini ko'rsatadi va ularni yangi faylga saqlaydi.
