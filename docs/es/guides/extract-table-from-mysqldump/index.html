Extraer una tabla de un archivo mysqldump

Un mysqldump completo de una base de datos puede ocupar decenas de gigabytes, y a menudo solo necesitas una tabla: para restaurarla, revisar sus datos o enviarla a alguien. BigText abre el volcado al instante sin cargarlo en memoria, y «Exportar líneas…» escribe cualquier rango de líneas en un archivo nuevo.

Paso a paso

  1. Abre el volcado

    Abre el archivo .sql con Archivo → Abrir o arrastrándolo a la ventana. Un volcado .sql.gz también se abre directamente.

  2. Lista las tablas

    mysqldump marca cada tabla con un comentario como -- Table structure for table `orders`. Busca -- Table structure for table y pulsa «Buscar todo»: los resultados listan todas las tablas del volcado con su número de línea.

  3. Encuentra dónde empieza y termina la tabla

    Haz clic en la tabla que necesitas en los resultados; su número de línea aparece en la barra de estado. Termina donde empieza el comentario de la siguiente tabla: F3 salta a él.

  4. Escríbela en un archivo

    Archivo → Exportar líneas… escribe un rango de líneas en un archivo nuevo: desde la primera línea de la tabla hasta la línea anterior a la siguiente tabla. Obtienes un .sql pequeño con la sentencia CREATE TABLE y las líneas INSERT de la tabla.

Conviene saber

  • El volcado empieza con líneas SET (juego de caracteres, comprobación de claves foráneas). Cópialas al principio del archivo nuevo si la tabla las necesita.
  • Un volcado hecho con --skip-comments no tiene esos comentarios: busca CREATE TABLE `orders` y el siguiente DROP TABLE IF EXISTS.
  • Solo los datos: la vista de filtro con INSERT INTO `orders` muestra solo las líneas INSERT de esa tabla y las guarda en un archivo nuevo.
