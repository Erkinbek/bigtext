打开 10 GB 的日志文件而不卡顿

Notepad++ 会提示超过 2 GB 的文件可能需要几分钟才能打开，VS Code 会把整个文件放进内存，两者在面对大日志时都可能卡死。BigText 只读取屏幕上的内容，所以 10 GB 或 50 GB 的日志都能即刻打开，内存只占约 100 MB。

操作步骤

  1. 打开它

    使用“文件 → 打开”，把文件拖到窗口上，或在终端运行 bigtext app.log（bigtext app.log:120 会直接打开到第 120 行）。用 .gz 和 .zst 压缩的日志可以直接打开。

  2. 快速跳转

    Ctrl+End 立即跳到最后一行。转到行（Ctrl+G）在行索引完成之前就能使用；在此之前行号前会带 ~。转到时间（Ctrl+Shift+T）接受 14:32:05，并跳到该时间的第一行。

  3. 找出错误

    日志上方的级别栏可筛选 ERROR、WARN、INFO 和 DEBUG 行，F8 跳到下一个错误。Ctrl+F 搜索整个文件，也可以使用正则表达式，“查找全部”会列出所有匹配。

  4. 只留关键内容

    筛选视图只显示匹配的行或只显示不匹配的行，就像对整个文件运行 grep，并可保存到新文件。

  5. 实时跟踪

    跟踪模式（bigtext -f app.log，或命令面板中的“跟踪文件变化（tail）”）会像 tail -F 一样追加新行，并能挺过日志轮转。服务器上的日志可用你的密钥通过 SSH 打开：bigtext -f user@server:/var/log/syslog。

小贴士

  • 可以把多个日志按时间合并到一个视图中，或让两个日志按时间同步滚动。
  • 搜索、筛选和保存都在后台运行，带进度条和取消按钮，窗口始终保持响应。
