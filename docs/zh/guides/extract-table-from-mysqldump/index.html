从 mysqldump 文件中提取单个表

一个数据库的完整 mysqldump 可能有几十 GB，而你常常只需要其中一个表：用来恢复、检查数据或发给别人。BigText 能即刻打开转储且不载入内存，“导出行…”可以把任意范围的行写入新文件。

操作步骤

  1. 打开转储

    通过“文件 → 打开”或把 .sql 文件拖到窗口上打开。.sql.gz 转储也可以直接打开。

  2. 列出所有表

    mysqldump 会用类似 -- Table structure for table `orders` 的注释标记每个表。搜索 -- Table structure for table 并点击“查找全部”：结果会列出转储中的每个表及其行号。

  3. 找到表的起止位置

    在结果中点击你需要的表，它的行号会显示在状态栏中。表在下一个表的注释开始处结束：F3 可跳过去。

  4. 写入文件

    “文件 → 导出行…”把一段行写入新文件：从该表的第一行到下一个表之前的那一行。你会得到一个包含 CREATE TABLE 语句和该表所有 INSERT 行的小 .sql 文件。

小贴士

  • 转储开头有 SET 语句（字符集、外键检查）。如果该表需要，请把它们复制到新文件的开头。
  • 用 --skip-comments 生成的转储没有这些注释：改为搜索 CREATE TABLE `orders` 和下一个 DROP TABLE IF EXISTS。
  • 只要数据：在筛选视图中输入 INSERT INTO `orders`，就只显示该表的 INSERT 行，并可保存到新文件。
