打开超过 Excel 1,048,576 行上限的 CSV 文件

Excel 的表格到第 1,048,576 行就结束了。打开更大的 CSV 时，它会提示数据过大，超出上限的行在保存时会丢失。日志、订单或数据库表的导出文件往往比这更大。

BigText 可以即刻把任意大小的 CSV 以表格打开，且从不载入内存：5000 万行的文件和 50 行的文件滚动起来一样快。它免费，可在 Windows、Linux 和 macOS 上运行。

操作步骤

  1. 打开文件

    下载 BigText，通过“文件 → 打开”或把 .csv/.tsv 文件拖到窗口上打开。它会以表格形式打开：分隔符（逗号、分号、制表符或竖线）从前几行自动识别，第一行成为固定的表头。Ctrl+T 可在表格和文本之间切换。

  2. 在文件中浏览

    滚动浏览，按 Ctrl+G 跳到某一行，或按 Ctrl+F 搜索整个文件；“查找全部”会列出每处匹配及其行号。无需等待加载，因为文件根本不会被载入。

  3. 不用 Excel 也能分析

    右键点击列标题：“统计…”（行数、空值和不同值、求和、平均值、最小值、最大值和最常见的值）、按此列筛选行、“按此列分组行…”并对另一列求和，以及“按此列透视…”。排序适用于 1 GB 以内的文件。

  4. 或者拆分给 Excel

    “文件 → 拆分文件…”会把 CSV 按指定行数（例如每份 1,000,000 行）切成 name.part001.csv、name.part002.csv……，总是在换行处切分。表头只在第一部分中，如果你的工具需要，请把它复制到其他部分。若只需要部分行，先筛选（“按条件筛选行…”），再把结果另存为一个更小的新 CSV。

小贴士

  • “视图 → 检查表格行…”会列出字段数不对、引号多余或数字列中混有文本的记录，并给出行号。
  • 同样的工具也可以在脚本中通过 bigtext-cli 使用，例如 bigtext-cli pivot。
