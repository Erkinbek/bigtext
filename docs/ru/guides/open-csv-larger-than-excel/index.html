Как открыть CSV-файл больше 1 048 576 строк Excel

Сетка Excel заканчивается на 1 048 576 строке. С CSV большего размера он предупреждает, что набор данных слишком велик, и строки за пределом пропадут при сохранении. Выгрузки логов, заказов или таблиц баз данных часто больше.

BigText сразу открывает CSV любого размера как таблицу и никогда не загружает его в память: файл на 50 миллионов строк прокручивается так же быстро, как на пятьдесят. Он бесплатный и работает в Windows, Linux и macOS.

По шагам

  1. Откройте файл

    Скачайте BigText и откройте .csv или .tsv через «Файл → Открыть» или перетащите его в окно. Он откроется как таблица: разделитель (запятая, точка с запятой, табуляция или вертикальная черта) определяется по первым строкам, первая строка становится закреплённым заголовком. Ctrl+T переключает между таблицей и текстом.

  2. Перемещайтесь по файлу

    Прокручивайте, нажмите Ctrl+G, чтобы перейти к строке, или Ctrl+F для поиска по всему файлу; «Найти все» покажет каждое совпадение с номером строки. Ждать загрузки не нужно: файл не загружается вовсе.

  3. Анализируйте без Excel

    Щёлкните правой кнопкой по заголовку столбца: «Статистика…» (строки, пустые и различные значения, сумма, среднее, минимум, максимум и частые значения), фильтр строк по столбцу, «Сгруппировать строки по этому столбцу…» с суммами другого столбца и сводная таблица. Сортировка работает для файлов до 1 ГБ.

  4. Или подгоните под Excel

    «Файл → Разделить файл…» режет CSV на name.part001.csv, name.part002.csv… по заданному числу строк, например 1 000 000, всегда по границе строки. Строка заголовка есть только в первой части — скопируйте её в остальные, если она нужна. Чтобы оставить только часть строк, отфильтруйте их («Фильтр строк по условиям…») и сохраните результат как новый, меньший CSV.

Полезно знать

  • «Вид → Проверить строки таблицы…» находит записи с неверным числом полей, лишней кавычкой или текстом в числовом столбце — с номерами строк.
  • Те же инструменты есть для скриптов в bigtext-cli, например bigtext-cli pivot.
