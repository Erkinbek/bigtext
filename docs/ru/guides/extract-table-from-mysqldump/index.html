Как извлечь одну таблицу из дампа mysqldump

Полный mysqldump базы может весить десятки гигабайт, а нужна из него часто одна таблица: восстановить её, проверить данные или отправить коллеге. BigText открывает дамп сразу, не загружая его в память, а «Экспорт строк…» записывает любой диапазон строк в новый файл.

По шагам

  1. Откройте дамп

    Откройте .sql через «Файл → Открыть» или перетащите в окно. Дамп в .sql.gz тоже открывается напрямую.

  2. Получите список таблиц

    mysqldump отмечает каждую таблицу комментарием вида -- Table structure for table `orders`. Найдите -- Table structure for table и нажмите «Найти все»: в результатах будут все таблицы дампа с номерами строк.

  3. Найдите начало и конец таблицы

    Щёлкните нужную таблицу в результатах — номер её строки виден в строке состояния. Конец таблицы там, где начинается комментарий следующей: F3 переходит к нему.

  4. Запишите её в файл

    «Файл → Экспорт строк…» записывает диапазон строк в новый файл: от первой строки таблицы до строки перед следующей таблицей. Получится небольшой .sql с CREATE TABLE и строками INSERT этой таблицы.

Полезно знать

  • Дамп начинается со строк SET (кодировка, проверка внешних ключей). Скопируйте их в начало нового файла, если они нужны таблице.
  • В дампе, сделанном с --skip-comments, таких комментариев нет: ищите CREATE TABLE `orders` и следующий DROP TABLE IF EXISTS.
  • Только данные: режим фильтра с INSERT INTO `orders` покажет лишь строки INSERT этой таблицы и сохранит их в новый файл.
